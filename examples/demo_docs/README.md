# Demo documents

Files to upload in the dashboard's Documents page.

| File | What it is |
|---|---|
| `hr_email.txt`, `patient_question.txt`, `no_sensitive_info.txt` | short made-up texts |
| `prescription_real_handwritten_1.jpg` | a real doctor's handwritten prescription (English): chronic urticaria, Fenadin 180 and Monocast 10 |
| `prescription_real_handwritten_2.jpg` | a real doctor's handwritten outpatient prescription, mostly Bangla: a hard case for the reading step |

The two prescriptions are images 0040 and 0420 of the *Image-to-Text Bilingual Dataset from
Medical Prescriptions* (Badhon, Islam, Zim, Hossain, Rangon and Islam, Mendeley Data, 2025,
doi:10.17632/tg2hm7n2bs.1), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
They come from hospitals, clinics and pharmacies in Gazipur, Bangladesh; the dataset's authors
blurred the patients' names and other identifying details. Only the file names were changed.
